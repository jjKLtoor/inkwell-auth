## 已完成

- [x] 独立 :source-auth Android 模块、纯 JVM 作用域契约与 Keystore 加密存储。
- [x] 同站 HTTPS 网页登录、独立 WebView profile、取消、持久 Cookie 保存与清理。
- [x] 来源详情「登录与会话」入口；登录页使用 Miuix 导航、状态卡、站点地址与按钮，网站内容保留 WebView。
- [x] BookSourceEngine 统一来源身份，接入搜索、发现、详情、目录、正文、图片及离线下载使用的引擎入口。
- [x] EngineJsHttp 同步及并发请求继承身份；CookieBridge 使用对应来源 CookieJar。
- [x] SourceBridge 登录信息按来源在内存读写；认证 Header 加密恢复、退出即时撤销。登录信息可能含密码，默认不落盘。
- [x] Cookie 按 origin、Domain、Path、Secure、Expires 匹配；响应 Cookie 轮换保存；跨端口跳转不携带身份。
- [x] 同域不同来源分开保存 Cookie；退出后的旧会话及迟到响应不能恢复已撤销凭据。
- [x] 会话请求日志隐藏详情；有认证材料时关闭规则调试内容输出，不因 Cookie 或 HTTP 200 提升为 VERIFIED。
- [x] 后台默认 WebView 不接收认证材料；另提供独立认证 profile，按受控 GET/HEAD 路径恢复 Cookie，具体限制见最新核查记录。
