# 通用脚本兼容与起点诊断（2026-11-18）

## 范围与验收

目标是修复自有通用模块中的兼容缺口，保持用户来源、书架与会话，不新增按站点名称或域名分支的专用客户端。本轮原计划排查多个来源，后按用户要求只做到番茄和起点，其他来源留待后续。番茄网页人形图标/登录按钮偶发不响应、红袖登录地址问题均暂缓，不能归因于 debug 包卡顿。

已有网页会话隔离、来源域名约束、Keystore 加密持久 Cookie、脚本登录续跑；这些不等于任意 Java 兼容或任意网站可用。验收分别记录本地夹具、安全边界、实机网页和引擎全链路，不用 HTTP 200、Cookie 数量或仪器测试执行成功代替来源通过。

## 通用修改

- `core/.../js/JdkCompat.kt`、`MemoryStreams.kt`、`BoundedNumbers.kt`：增加 UUID、字符集、受限内存流/GZIP、SecureRandom 与 BigInteger 替身。限制内存、整数位数和原生计算预算，保留取消与沙箱；不开放文件、反射或任意 Java 类。
- `GuardedUrlConnection.kt`、`JsBridges.kt`、`EngineJsHttp.kt`、`SessionBoundJsHttp.kt`：Java 风格 URL 连接仅转接既有受控 HTTP 出口。二进制请求/响应限制 4 MiB，最长 45 秒，禁止自动重放和自动重定向；句柄绑定所属来源会话，退出或跨来源复用会拒绝。
- `ScriptRuntime.kt`：计算预算随外层脚本重置，嵌套调用不能重置预算逃逸。
- `SourceHttpClient.kt`：原有请求默认行为保持；受控二进制连接可收紧响应上限并禁用重试。增加关闭匿名内存 CookieJar 的选项，供 WebView 代理使用。
- `source-auth/.../AuthenticatedWebViewProfile.kt`：被拒绝的子请求不再直接判整张页面失败；主文档约束保留。代理不再另存 Cookie，避免 OkHttp 的 BridgeInterceptor 用旧缓存覆盖 WebView 刚更新的 Cookie，或覆盖域外资源显式的空 Cookie。WebView profile 是该代理唯一 Cookie 所有者。

没有修改用户导入的 JSON、CSS 选择器、站点设备注册或签名算法，没有放开原生网络、私网、证书、POST 渲染或认证作用域。通用能力不代表所有来源都兼容；过期规则、不同移动/桌面页面、网站验证和访问限制仍需区分。

在加入通用脚本替身的候选包上，实际来源全链路测试得到：搜索 10 条、详情成功、目录 1 章、正文 7608 字符，界面显示全链路通过。正文仅记录字符数，未采集预览。用户另行反馈来源管理校验通过；只读界面观察为「可用 · 4.1 秒」。这是当时账号、来源和测试条目的结果，不推广到其他条目或平台授权。

随后增加的跨会话连接句柄检查、BigInteger 符号/字节数组构造和代理 Cookie 修复已通过本地回归；最终包未重跑番茄真实全链路。此前历史记录中的目录失败属于较早包，保留原始失败证据。

### 起点

1. 旧实现诊断：已有会话，搜索 HTTP 200、HTML 186 字符、搜索列表 0；同一轮可观察多次主文档 GET。来源管理此前保存的错误为带认证渲染超时，该字段不是本轮新校验结果。
2. 关闭代理的第二份 CookieJar 后：返回页面约 16851 字符，重复主文档请求减少。最终诊断可见文本 18 字符、包含「验证」，外部脚本 origin 为 `https://ssl.captcha.qq.com:443`，搜索列表仍为 0。
3. 用户再次手动登录、点击应用底部保存会话。之后界面全链路测试实际显示「搜索: 0 条结果」「失败: 搜索无结果」。**起点后台搜索未通过，详情、目录、正文没有因此得到验证。**
4. 用户在交互网页搜索「剑」，明确反馈有结果；随后实际截图确认多条结果，页面显示 `m.qidian.com`。来源 JSON 搜索地址是 `www.qidian.com/so/{{key}}.html?page={{page}}`、声明 `webView:true`，并带桌面 UA；网页登录使用 WebView 自身 UA。两种路径和页面不同，不能将网页成功计为引擎成功，也尚不能断言地址、UA、代理网络差异中哪一项是验证触发的唯一原因。

没有自动切换至移动站、替换来源规则或扩大来源认证范围，也没有尝试绕过网站验证。按用户「测完起点先结束」收尾；起点接口兼容问题仍未完成，后续应基于上述对照继续，不能要求用户无依据地反复登录。

诊断类 `SourceSiteDiagnosticTest` 必须显式指定来源名和搜索探测参数；默认跳过。不导出账号、原始规则、Cookie、完整请求地址、HTML 或正文，只记录数量、origin、规则哈希、预先限定的状态词和请求类别。已有校验字段与本轮探测字段分开。一次诊断进程未按预期结束，人工停止；该次遗留 JSON 不计为新证据，后续成功执行有单独日志。
