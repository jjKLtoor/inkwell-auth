下面保留排查过程中的失败与中间结果，不能将其读作最终仍未通过。最终 Release 待用户自行实测。

## 登录与取页请求配置衔接

确认此前交互登录固定使用系统 WebView User-Agent，而后台按来源明确声明的 User-Agent 取页。新增通用静态声明衔接：ViewModel 读取来源静态 header 中的 User-Agent，LoginWebSession 在启动前应用，同一会话内不可切换，弹窗沿用。未声明时保持系统默认；不生成指纹、不添加站点分支、不修改 Cookie 域或放开认证范围；动态 header 脚本的 User-Agent 未在网页登录执行。

`login-context-build.log`：全模块 1088 项本地回归与 debug 构建通过，43 秒。`LoginRequestContextTest` 在真实 Chromium 中用人工响应验证声明值实际出现在请求中、无声明时使用系统值、启动后禁止切换，1 项通过，1.366 秒；不是站点登录验证。

实机保留数据更新后，起点网页登录显示 www.qidian.com，不再像此前进入 m.qidian.com。用户在该桌面页完成正常登录并保存，之后完整验证见本文件开头；不是把入口变化本身算成来源通过。

## 渲染时序修正

旧逻辑只看 DOM 签名连续不变，异步数据请求尚在执行时也可能返回空壳。隔离代理现在提供在途请求数和请求版本；渲染稳定判断结合这些状态及 document.readyState。主文档、私网、证书、域名和 HTTP 方法限制保持，原总超时未扩大。没有新增平台域名分支，也没有抓取或绕过验证码。

新增真实 Chromium 夹具：主文档先完成，数据 XHR 延迟 2 秒才返回，DOM 初期保持不变，验证引擎等待并取得结果。`render-readiness-device.log` 的该夹具及原有 3 项共 4 项通过，7.689 秒；这是人工响应，和起点真实站点证据分别记录。

修正过程中起点先达到搜索 10 条、目录 595 章，曾在正文阶段触及原 60 秒测试时限；其后完整复测在 6.825 秒通过。诊断另允许 110 秒观察阶段耗时，但本次真实通过没有依赖延长时限。未做各单项修正独立回滚的真实网站对照，不能将所有瞬时网络差异归因于某一行改动。

本轮目标：在用户实机继续排查两个来源，保持 fork 版本 0.5.9，修复通用测试及会话衔接问题。设备原为 Release，用户明确要求安装 Debug 后，已使用同签名、同版本保留数据覆盖；没有卸载或清空来源、书架、阅读记录。账号和网页登录由用户操作。

## 通用修正

`SearchRuleSet` 新增 `checkKeyWord` 解析和序列化保留；`sourceTestKeyword` 按手动指定 > 来源声明 > 通用默认词选择。详情页预填来源校验词，异步加载不覆盖用户已经输入的词。批量校验留空时逐来源选词，有手动输入则保留。普通搜索、来源地址与认证作用域均未改变，不含平台名称/域名分支。

旧版解析器未保留该字段，手机现有来源的诊断显示该字段缺失；新实现不会自动重写或补齐用户已有来源。QQ 阅读本轮通过使用的是手动输入校验词。新导入/重新导入的来源才可保留该字段；未自动更新用户 JSON。

为核对用户提出的移动站 Cookie 假设，Debug 包在网页登录保存时新增受限诊断：记录收集与作用域过滤前后的数量、域、host-only 与保留标记，存于应用 noBackup 调试文件。不记录 Cookie 名称、值、路径、账号、完整地址；Release 不写该记录，不进入备份或 Git，也不扩大 Cookie 发送范围。该数量是捕获记录数，跨已访问 URL 可能有重复，不作为唯一 Cookie 数量。

用户再次登录并保存后的统计：收集记录 1161、保留记录 930。qidian.com 非 host-only 保留 924，www.qidian.com host-only 保留 6；m.qidian.com 非 host-only 排除 15，yuewen.com 排除 210，ptlogin.qidian.com host-only 排除 2，ptlogin.yuewen.com host-only 排除 4。该结果证明有移动站域 Cookie 被排除，但不能识别其是否为关键登录材料，更不能改域后发送给 www。共享域和 www 的材料已保留，过滤符合 Cookie 域规则。

此后来源登录页显示已保存 12 条 Cookie，未重启进程直接用声明校验词再次测试，仍搜索 0 条。不能认定 Cookie 子域差异为唯一原因。公开移动首页未找到桌面站切换链接；没有猜测登录地址或绕过验证。证据为本地忽略文件 auth-capture-scope-diagnostic.json 和实际设备界面。
