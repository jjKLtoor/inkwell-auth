## 修复已证实的副本缺陷

新增 HTTPS MockWebServer 复现发现，同一凭据同时存在于 CookieJar 和脚本保存的原始 `Cookie` Header 时，删除 CookieJar 中最后一条后，原始 Header 会重新发出旧值。此次番茄匿名请求无该 Header，故这里修复的是另外一条已证实的通用路径。删除项现在同步清除保存的 Cookie Header 中名称和值都相同的条目，以及内存登录 JSON 中同值的直接字段，保留其他 Cookie 和独立认证头。操作与既有撤销、加密保存和失败恢复使用同一事务顺序。复杂的脚本派生值和不同 Token 无法从单个 Cookie 推断归属，完整会话使用「退出登录」。UI 删除确认也说明了这一点。独立匿名访问与本地缓存继续可用。

新增测试在修正前捕获了旧 `sid`，修正后实际收到的 Cookie 请求头只保留无关项。重新构造会话管理器和加密存储后同样不发送旧值。退出后请求没有 Cookie，明确保存新会话后请求发送新值。使用合成凭据及本地 TLS 服务器，不计为番茄真实登录。
