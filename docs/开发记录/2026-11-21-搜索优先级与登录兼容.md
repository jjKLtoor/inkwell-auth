# 来源搜索优先级与网页登录兼容

## 搜索调度

在「来源管理 → 来源详情 → 搜索优先级」可为可搜索来源选择最高、优先或默认。使用本机 DataStore 按来源 ID 保存，已有及未标记的来源默认为默认。规则重新导入时沿用相同 ID 的偏好，普通规则 JSON 和同步备份不包含该设置。

首轮全局搜索把优先级作为配置快照，最高档的请求全部收尾后才启动优先档，优先档收尾后才启动默认档。同档沿用原测速、失败恢复探测、手动顺序与并发上限。首轮暂停恢复继续按档调度。「加载更多」保留原有并发顺序。原有精确命中提前结束只在进入默认档后生效。停用、无搜索规则、站点限流冷却和网络超时仍按原逻辑处理。

「加载更多」只访问上一页仍报告有后续结果的来源，页码递增，重复书目按书名与作者合并。同一来源重复返回整页时不继续为它翻页。已加入书架的书沿用其当前绑定来源，目录、正文及换源机制沿用上游流程。

## 登录兼容

用户确认当前 Cookie 登录已正常使用，以该流程为回归基线。`WebLoginTarget` 扩展对 `java.startBrowser` 和 `java.startBrowserAwait` 参数的静态提取，支持字符串及 `source.bookSourceUrl` 拼接。登录窗口与弹窗支持网站按原生 Cookie 规则执行跨站认证。主页面导航与网页资源分别记录，资源较多时回跳页仍参与 Cookie 采集。会话保存范围、Keystore、请求作用域、证书及私网保护沿用原实现，无新增网站特例。
