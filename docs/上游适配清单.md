## 能力边界

- 新容器只有内存存取，没有 Keystore、持久化、Cookie 存储、WebView 桥接或引擎集成。容器间的来源隔离测试不能证明现有共享 CookieJar 已隔离。
- 契约默认状态 UNKNOWN；没有自动登录校验器。状态由调用者提供，不因 Cookie 或 HTTP 状态自动变成 VERIFIED。
- 页面识别仅支持同 origin HTTPS 绝对地址与 `/`、`./`、`../` 开头的相对路径。拒绝凭据 URL、明文 HTTP、跨域 / 子域 / 端口变化、私网字面量；DNS 与实际导航仍依赖后续网络防护。
- JS、动态模板、自定义 loginUi、裸相对路径（如 `login.html`）暂不支持；不执行脚本猜测页面。识别页面不代表已有登录 UI。
- 不注册 Koin 认证实现、不注入网络请求、不修改 Room / 备份 / 用户来源或阅读记录。

以上为阶段 A 的容器边界。阶段 B 新增独立加密存储与网页登录预览，不改变上述旧容器或现有网络实现：

| 阶段 B 位置 | 用途 | 上游合并风险 |
|---|---|---|
| `source-auth/` 新增存储 / WebView / Cookie 转换及测试 | 独立会话与加密持久化 | 低：新模块内部 |
| `core/.../source/auth/SourceAuthContext.kt` | 只新增 origin 访问器 | 低：新目录 |
| `app/.../ui/sourceauth/` | 登录预览与会话管理页面 | 低：新目录 |

| `AppModules.kt` | Keystore 存储及 ViewModel Koin 注册 | 中：按上游 DI 调整注册即可 |

```powershell
.\gradlew.bat :core:test :reader:test :app:testDebugUnitTest :source-auth:testDebugUnitTest
.\gradlew.bat assembleDebug
```
